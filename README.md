# Pomodoro Timer

Simple focus timer using the Pomodoro Technique.

## The Pomodoro Technique

1. **Work** - 25 minutes of focused work
2. **Short Break** - 5 minutes rest
3. **Repeat** - Complete 4 pomodoros
4. **Long Break** - 15-30 minute break

## Features

- **Work Timer** - 25 minute focus sessions (red)
- **Short Break** - 5 minute breaks (teal)
- **Long Break** - Longer rest periods (purple)
- **Audio Notifications** - Sound when timer ends
- **Visual Countdown** - Large, easy-to-read display
- **Session Counter** - Track completed pomodoros

## Usage

1. Open `index.html` in a browser
2. Click Start to begin a work session
3. Focus until the timer ends
4. Take your break
5. Repeat!

## Why Pomodoro?

- Prevents burnout
- Maintains focus
- Creates urgency
- Regular breaks improve retention
- Easy to track productivity

## Tech

- Single HTML file (no build needed)
- CSS variables for theme colors
- JetBrains Mono font for timer display
- Works offline
