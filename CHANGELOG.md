# Changelog

All notable changes to Pomodoro Timer.

## [1.1.0] - 2026-02-22

### Added
- **PWA Support** - Install as a standalone app on mobile/desktop
- **Social Meta Tags** - Better sharing previews on social media
- **Manifest & Service Worker** - Offline-capable progressive web app
- **Custom Favicon** - SVG favicon with tomato timer icon

---

## [1.0.0] - 2026-02-03

### Added
- **Initial Release**
- 25-minute work timer (Pomodoro)
- 5-minute short break timer
- Long break option
- Audio notification when timer ends
- Visual countdown display
- Session counter for completed pomodoros
- Start/Pause/Reset controls
- Timer mode switching (Work/Short Break/Long Break)
- JetBrains Mono font for clean timer display
- Color-coded modes (red=work, teal=break, purple=long break)
